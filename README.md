# VOID BYPASS v2.1

Mobile-first black-and-white fictional command/scan simulator.

## Run
Extract the ZIP and open `index.html` in Android Chrome or a desktop browser.

## Features
- Minimal command entry page and ENTER action
- Natural-language keyword classification for fictional command vs scan scenarios
- Sequential checklist and animated text console side by side on desktop; stacked on phones
- Simulated file/model catalogue, mock login state, notebook entry, person placeholder, and synthetic location card
- Configurable output density, animation speed, and auto-scroll (saved in localStorage)

## Safety
This is a local visual simulation only. It does not execute commands or user code; access files/accounts; use camera/GPS; scan devices; identify or track people; connect to networks; or bypass security. All output is fabricated. Any location example is synthetic, clearly labeled fake, and not a person's location.
